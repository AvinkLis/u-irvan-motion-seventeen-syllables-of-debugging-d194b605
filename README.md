Entry for the make.fun bounty [Seventeen Syllables of Debugging](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605).

The program (`main.ts`, Node 22, standard library only) writes one haiku
about debugging — three lines in the 5-7-5 syllable shape, 70 characters
in total — to `entry.txt` in the output directory
(`$MAKEFUN_OUTPUT_DIR`, or `/output` by default). The build is green, one
line comes out, and the last line reveals what that line was holding up.

Run it with:

```sh
node main.ts
```
